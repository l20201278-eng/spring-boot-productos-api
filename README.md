# API REST de Productos

Este proyecto implementa una API REST para gestionar productos utilizando Spring Boot, Spring Data JPA y una base de datos H2 en memoria.

## Tecnologías utilizadas

*   Java 17
*   Spring Boot
*   Spring Data JPA
*   H2 Database
*   Maven

## Requisitos

*   Java Development Kit (JDK) 17 o superior
*   Maven
*   Un cliente REST como Postman o curl
